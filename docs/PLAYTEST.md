# Unfold Study A01 — 테스트 방법

이 버전은 완성 게임의 볼륨을 검증하는 빌드가 아니라, 핵심 조작과 제안된 연쇄 규칙을 비교하는 3D 프로토타입이다. 예전 프로토타입의 게임 코드와 화면은 사용하지 않았다. Noto Sans KR 글꼴만 OFL에 따라 다시 사용한다.

## 유지한 합의

Chicka를 펼치면 길이 생기고, 더 작은 열차가 이동한 뒤 내부 Chicka가 하차한다. 열차는 사라지고 길은 남는다. 한 번에 한 겹을 사용하고 하차해도 남은 횟수가 초기화되지 않는다. 화면 가독성을 위해 하차 후 Chicka 표시 크기는 동일하게 유지한다. 크기 감소와 카메라의 재귀적 확대는 아직 설계하지 않는다.

## 이번에 실험할 제안

- 여러 Chicka의 펼침을 기존 길을 통해 연결하는 신호 연쇄. ON/OFF 비교 가능.
- 직선: 4칸. 굽은 길: 앞 2칸 후 왼쪽 2칸. 교량: 4칸, 중간 교차 신호 절연. 분기: 앞 4칸으로 열차 이동, 중간에서 왼쪽 2칸으로 신호 분기.
- 겹 순서는 바깥부터 사용하며 미리 볼 수 있다. 선택한 Chicka의 방향을 드래그나 Q/E로 바꾼다. 다른 Chicka는 표시된 방향으로 자동 펼쳐진다.
- 신호 연결은 모든 결과를 미리 계산한 뒤 순서대로 연출한다. 실제 신호 도착 시간에 따른 판정이나 동시 열차 충돌은 이번 범위 밖이다.
- 신호는 연결된 기존 길 전체를 이용한다. 교량 중간은 연결하지 않고 양 끝만 연결한다. 같은 Chicka 계통은 한 연쇄에 한 번만 펼친다. 경계 밖 자동 펼침은 겹을 소비하지 않고 미리보기에 표시한다.
- 점수는 한 연쇄의 펼침 개수에 따라 10 + 20 + 30 …이다. 점수와 재미 사이의 관계는 아직 검증되지 않았다.

## 약 10분 플레이 순서

1. **첫 펼침:** 직접 드래그로 한 겹 펼친다. 열차를 보고 하차한 Chicka를 다시 선택한다. 회전과 되돌리기를 시도한다.
2. **이어지는 운행:** PIP을 기본 방향으로 펼친다. 연쇄가 어디까지 이어질지 행동 전에 말해 본다. 되돌리고 연쇄 OFF에서 같은 행동을 반복한다. 두 방식 중 더 조작하고 싶은 쪽을 기록한다.
3. **겹의 순서:** 각 Chicka를 선택해 내부 순서를 확인한다. 분기와 기존 길을 활용한 연결을 시도하고 교량의 절연을 비교한다.
4. 세 장면 중 하나를 다시 해 본다. 외부에서 다시 하라고 시키지 않았다면 스스로 다시 할 의사가 있었는지 답한다.

## 피드백 질문

| 항목 | 질문 |
| --- | --- |
| 조작 | 잡고 놓을 때 내가 직접 펼치는 느낌이 드는가? 점수 없이도 반복하고 싶은가? |
| 전개 | 열차가 나오는 과정은 즐거운가, 아니면 다음 조작까지 기다리는 시간인가? |
| 예측 | 예상 길·하차 위치·자동으로 열리는 Chicka를 행동 전에 설명할 수 있는가? |
| 연쇄 | ON에서 내 선택이 결과를 만들었다고 느끼는가, 자동 재생을 본 느낌인가? |
| 내부 구조 | 다음 겹을 보고 현재 방향을 바꾼 적이 있는가? |
| 차별성 | 가장 먼저 떠오른 다른 게임은 무엇이며, 실제 판단도 비슷한가? |
| 구매 의향 | 이 조작을 발전시킨 게임에 관심이 있는가? 유료 구매를 위해 가장 부족한 점은 무엇인가? |

## 다음 방향을 정할 기준

- 조작은 좋지만 연쇄가 불명확하면: 새 콘텐츠보다 신호·예측 표현을 먼저 수정한다.
- 연쇄는 보기 좋지만 선택이 단순하면: 겹 순서나 목표의 의미를 수정한다. 자동으로 열린 수만으로 재미를 판정하지 않는다.
- 이동을 기다리는 것이 지루하면: 이동 시간을 단축하거나 여러 행동의 겹침을 실험한다.
- 기본 펼침 자체가 반복하고 싶지 않다면: 추가 콘텐츠·상점·해금 제작을 멈추고 핵심 조작부터 다시 검토한다.

자동 테스트 통과와 연쇄 점수 차이는 재미·독창성·5~10달러 구매 의향을 입증하지 않는다. 실제 사람의 피드백을 받은 뒤 방향을 정한다.
